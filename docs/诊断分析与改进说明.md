## 1. 当前预测结果概览

测试集（2025 年全年）7 天预报指标：

```
  Day   RMSE(°C)   MAE(°C)
    1     0.287      0.194
    3     0.448      0.302
    5     0.549      0.369
    7     0.625      0.421
  avg     0.483      0.326
```

对比 persistence baseline（重复最后一天 SSTA）：

```
  Day   RMSE(°C)
    1     0.379       ← persistence Day1: 模型优 24%
    7     0.765       ← persistence Day7: 模型优 18%
```

模型在逐天 RMSE 上全面优于 persistence，但差距随 lead day 增大而缩小。

## 2. 误差空间分布：为什么日本沿岸大、赤道小

### 2.1 观测数据

诊断实验 1.2 的区域 RMSE：

```
  Region                    Day1    Day7    特征
  Equatorial_CPacific       0.138   0.230   ← 最低误差
  Equatorial_WPacific       0.198   0.365
  Subtropical               0.216   0.541
  Open_Ocean                0.391   0.821
  Kuroshio                  0.429   0.940   ← 误差集中的关键区域
  Oyashio                   0.530   1.122   ← 最高误差
```

纬度–经度热力图（诊断 1.1 输出）清楚地显示：**误差热点集中在 35°N–50°N、140°E–165°E 的 Kuroshio–Oyashio 交汇区**。

### 2.2 物理原因

这**不是模型缺陷，而是海洋物理的天然属性**：

#### 原因一：SST 变率本身存在巨大空间差异

赤道太平洋（10°N–20°N）的日际 SST 变化量约为 ±0.2°C，而 Kuroshio/Oyashio 锋面区的日际变化可达 ±1.5°C 甚至更高。SST 的**可预测性上界**（intrinsic predictability limit）在赤道区天然更高（信号更多来自缓慢的大尺度过程），而在中纬度锋面区天然更低（湍流、涡旋、锋面摆动主导）。

这意味着即使是一个完美的物理模型，Kuroshio 区域的 RMSE 也会是赤道的 3–5 倍——当前模型的误差空间分布基本符合这个天然约束。

#### 原因二：0.25° 分辨率无法分辨锋面涡旋

Kuroshio 延伸体区域的涡旋半径约为 30–80 km，而 0.25° 格点对应 ~28 km。格点刚好能"看到"涡旋存在，但无法解析其内部结构。模型在每个格点上预测的是该 28×28 km² 区域的平均 SST，而锋面附近的 SST 在 28 km 内可以变化 2–3°C——这导致单个格点的预测误差天然偏高。

#### 原因三：SLA（海平面异常）数据在近岸有缺失

CMEMS AVISO 的卫星高度计数据在距离海岸 ~30 km 内有严重缺失或噪声。第 4 通道 SLA 在日本沿岸的输入质量明显低于开阔大洋，削弱了模型对该区域的动力学感知。

### 2.3 诊断指标确认

诊断 1.1 的 top-5% 误差分析显示，**5% 的海区贡献了 5% 的总误差**（而非幂律分布的 20-30%），说明误差集中在可预期的物理区域，而不是模型有系统性盲区。

## 3. 空间结构：学到了什么、怎么学到的

### 3.1 证据：诊断指标的前后对比

| 指标 | 旧版本 (纯 MSE) | 当前版本 (+物理通道+多物理损失) | 变化 |
|------|:---:|:---:|:---:|
| grad bias (梯度幅度偏差) | –0.237 | **–0.013** | 几乎消失 |
| grad angle error (梯度方向误差) | 109.3° | **49.7°** | 从随机降至接近正确 |
| persistence worse % (差于persistence的像素) | 100.0% | **6.9%** | 从全局差→仅局部差 |
| Day7 corr<0.5 % (低时间相关像素) | 100.0% | **7.7%** | 同上 |

### 3.2 如何解读这些指标的改善

#### grad bias: –0.237 → –0.013

旧版 grad bias 为负，意味着 `|∇SST_pred| < |∇SST_true|`——模型输出的锋面比真实的"圆滑"。这是 Transformer attention 的经典过平滑行为：attention 对邻域做加权求和，等价于空间平滑核。新版的 grad bias 接近零，说明预测的梯度幅度与真实值基本匹配——**锋面不再被系统性抹平**。

#### grad angle error: 109° → 50°

旧版的 109° 意味着 `∇SST_pred · ∇SST_true < 0`（点积为负），即 **pred 的梯度方向与 true 的梯度方向几乎相反**——这是完全失败的空间建模。新版的 50°（仅略高于 45° 阈值）意味着至少有一半以上的像素梯度方向与真实接近一致。考虑到 SST 锋面本身的噪声水平，50° 是一个"空间结构已大部分学到"的信号。

#### persistence worse: 100% → 6.9%

旧版 100% worse 意味着模型的**每一个**海洋像素都比 persistence（简单重复昨天）更差——这说明旧版模型连 Day1 的"基本复制"都做不好。新版 6.9% 意味着 93.1% 的像素上模型优于或等于 persistence——**在这些像素上，模型的绝对 SSTA 预测是有信息的**。

注意：6.9% worse 的像素恰好集中在前述的高变率锋面区，这符合物理预期。

### 3.3 什么改动带来了这些改善：三重机制

#### 机制一：物理通道 (grad_x, grad_y, advection)

**改动**：在 `nw_pacific_dataset.py` 的 `build_data_array` 中，在归一化后的基础 4 通道数据上计算 3 个派生通道并堆叠：

```python
grad_x    = ∂(SSTA)/∂lon          # 东西向温度梯度
grad_y    = ∂(SSTA)/∂lat          # 南北向温度梯度
advection = -(u10·grad_x + v10·grad_y)  # 风驱平流项
```

每个通道独立 z-score 归一化后与原有 4 通道拼接为 7 通道输入。

**为什么有效**：Transformer 的 self-attention 本质是：

```
output_i = Σ_j softmax(Q_i · K_j) × V_j
```

即"对所有位置的值做加权平均"。当所有位置的 V（SSTA）值相似时，attention 无法区分锋面和均匀区。但 grad_x/grad_y 在锋面两侧符号相反（一侧正一侧负），形成强对比——attention 的 softmax 倾向于给特征值差异大的位置更高的权重区分度。**梯度通道让 attention 在计算 Q·K 相似度时能够"看到"锋面边界，从而在 V 聚合时不跨锋面平均。**

advection 通道更进一步：它不只是一个"标记"，而是直接编码了"风正在向哪个方向推动 SST"这一定量动力学信号。这是将 PDE 先验注入 attention 输入空间的最低成本方式。

#### 机制二：空间梯度损失 (loss_grad = 0.5 × MSE(grad(delta), grad(delta_ref)))

**改动**：在 `_compute_loss` 中，不在 `pred = X_last + delta` 上算梯度（因为 X_last 的梯度会主导掩盖 delta 的贡献），而是在**纯 delta** 上算：

```python
delta = pred - X_last                     # 模型实际预测的 SST 变化场
delta_ref = Y - X_last                    # 真实的 SST 变化场
loss_grad = MSE(grad(delta), grad(delta_ref))  # 逼迫 delta 的空间结构匹配真实变化
```

**为什么有效**：单纯 MSE 对"方向错误"是不敏感的——如果模型把锋面位置错移了一个格点，MSE 的惩罚只来自幅度差，梯度的方向错误完全不被惩罚。`loss_grad` 直接计算梯度向量之间的 MSE，迫使模型**把 SST 变化放在正确的位置**：

- 如果真实变化在 Kuroshio 锋面上是 +0.5°C 的升温条带，模型的 delta 也必须在同样的纬度和空间形态上产生一个条带状变化
- 如果模型通过"全局均匀加温"来降低 MSE，`loss_grad` 会很大（均匀场的梯度 ≈ 0，而真实变化场有清晰的梯度）

#### 机制三：梯度损失的掩膜设计

梯度损失只在"两个空间邻居都是海洋"的像素上计算：

```python
m_gx = mask[:, :, :, 1:] * mask[:, :, :, :-1]  # 右邻居和自身都是海洋
m_gy = mask[:, :, 1:]  * mask[:, :, :-1]        # 上邻居和自身都是海洋
```

这避免了海岸线上"海洋 vs 陆地（值=0）"造成的人工大梯度污染梯度损失信号。

### 3.4 小结

**模型学到空间结构，是通过"显式提供梯度信息作为输入通道 + 用梯度 MSE 作为损失约束"这一对手段实现的。** 本质上是给 Transformer 的 attention 机制注入了"边界感知"能力，同时通过损失函数逼迫模型使用这种能力来输出空间结构正确的变化场。

## 4. 时间动力学：为什么没学到

### 4.1 核心证据

| 指标 | 当前值 | 物理含义 |
|------|:------:|---------|
| ACF lag-6 pred | **0.985** | 模型预测的 Day1 和 Day7 几乎完全一样 |
| ACF lag-6 truth | 0.737 | 真实 SST 在一周内有显著变化 |
| dSST/dt corr | **0.085** | 模型预测的逐日变化量与真实变化几乎不相关 |
| RMSE growth ratio | **0.93** | 模型误差增速与 persistence (ratio=1.0) 几乎相同 |

这三个指标指向同一个结论：**模型的 7 天预测序列之间几乎没有有意义的差异**——ACF=0.985 意味着 `pred_Day1 ≈ pred_Day2 ≈ ... ≈ pred_Day7`，而真实 SST 的 ACF=0.737 意味着每周有显著的演化。模型在做的就是"学到一个最佳的平均状态，然后对 7 天输出几乎同一个值"。

### 4.2 根本原因：Decoder 架构无因果时间依赖

这是最核心的架构约束，与损失函数无关。

```
模型的 Decoder 工作方式:

  decoder_query_0  →  cross_attn(memory) → self_attn → output[0]  (Day 1)
  decoder_query_1  →  cross_attn(memory) → self_attn → output[1]  (Day 2)
  decoder_query_2  →  cross_attn(memory) → self_attn → output[2]  (Day 3)
  ...
  decoder_query_6  →  cross_attn(memory) → self_attn → output[6]  (Day 7)

所有 7 个 query 共享同一套 cross-attention 的 encoder memory (14 天历史),
query 之间的 self-attention 是双向的（非因果），
output[2] 不依赖 output[1] 的值, 只依赖"是否有一个 query 维度专门用于 Day 2"。
```

这意味着什么？用控制论的术语来说：**这是一个 open-loop 预测器，不是 closed-loop 动力系统**。

模型对未来的预测完全由 encoder memory（历史 14 天的编码）决定，7 天的输出之间没有信息流动。对模型而言，要降低 loss，只需要让 decoder 的 7 个 query embedding 学到"分别对 encoder memory 的不同子空间做 cross-attention"，从而输出稍微不同的值。

**这等价于做 7 次独立的"从历史到未来"的映射**，而不是做 1 次"从历史到第 1 天，再从第 1 天到第 2 天..."的动力学演化。

### 4.3 为什么多物理损失无法打破这个约束

#### loss_tend (λ=5.0) 为什么失效

```python
loss_tend = MSE(pred[t+1] - pred[t], Y[t+1] - Y[t])
```

这个损失惩罚的是 `pred` 序列内部的变化量与真实变化量之间的差异。理想情况下，这应该逼迫模型让 `pred[t]` 逐日不同。

但问题是：**Decoder 的所有输出是并行计算的，不存在 `pred[t+1] = f(pred[t])` 的因果依赖。** 模型从随机初始化的 decoder query embedding 开始优化，为了让 `loss_tend` 变小，它可以：

1. (正确的做法) 学会让 `query_1` 编码"1 天后的状态"，`query_2` 编码"2 天后的状态"...
2. (更简单的做法) 让所有 query 编码相似的"平均状态"，然后通过对 memory 做稍有不同的 cross-attention 来产生微小差异

选项 2 的优化难度远低于选项 1，因为选项 1 需要模型在没有时间递推机制的情况下凭空学会"1 天后"与"2 天后"之间的物理因果关系。

**实验证据**：λ_tend 从 0.5 提升到 2.0 再到 5.0，ACF lag-6 始终维持在 0.98-0.99，没有任何改善。这不是权重不够的问题，是梯度无法传递到正确参数的问题。

#### 为什么之前的 Pearson 相关失败了

早期版本使用 `_masked_pearson(dt_pred, dt_true)` 作为趋势损失，认为 Pearson 相关系数比 MSE 更关注"方向"而非"幅度"。

但存在一个根本性的度量错误：

```python
# _masked_pearson 实际做的事情:
all_pixels = dt_pred[mask].ravel()   # 把 B×(T-1)×H×W ≈ 336,000 个值打平为一维
all_truth  = dt_true[mask].ravel()
corr = pearson(all_pixels, all_truth)  # ← 这是"全局空间相关"，不是"时间动态相关"
```

在 SST 数据中，**空间 SST 模式每天的分布非常相似**（今天冷的地方明天通常还是冷的），所以这个"全局打平 Pearson"自然 ≈ 0.98，不管 `dt_pred` 是 0 还是正确的变化量。这是典型的**把空间自相关误认为时间预测能力**的错误。

### 4.4 时间动力学失败的完整因果链

```
架构约束
  │
  ├─→ Decoder 无因果时间依赖 (所有 7 步并行生成)
  │     │
  │     └─→ 模型的最优策略: 所有 query 学"平均状态"
  │           │
  │           └─→ pred_Day1 ≈ pred_Day2 ≈ ... ≈ pred_Day7
  │                 │
  │                 ├─→ ACF_pred = 0.985 (几乎不衰减)
  │                 ├─→ dSST/dt corr = 0.085 (变化量几乎为零)
  │                 └─→ RMSE growth ratio = 0.93 (误差增长≈persistence)
  │
  └─→ 损失函数的梯度信号无法"穿过"并行生成的架构约束
        │
        ├─→ loss_tend: 模型选择让所有 query 近似来降低此项
        └─→ loss_grad: 可以降低（空间结构在 delta 上也能优化）
```

## 5. 已尝试手段的效果总结

| 改动 | 目标 | 对空间结构的改善 | 对时间动力学的改善 | 原理 |
|------|------|:---:|:---:|------|
| **物理通道** (grad_x, grad_y, advection) | 让 attention 感知锋面 | ✅ 显著 | ❌ 无 | 显式注入边界信号，防止跨锋面平均 |
| **梯度损失** (loss_grad in delta) | 强制 delta 场有正确空间结构 | ✅ 显著 | ❌ 无 | 惩罚"均匀加温"策略，逼出条带/涡旋结构 |
| **趋势损失** (loss_tend, λ=5.0) | 逼迫逐日变化 | ❌ 无 | ❌ 无 | 梯度被架构阻断，模型绕过 |
| **反持续损失** (loss_anti) | 防止退化到 persistence | ❌ 无 | ❌ 无 | 模型已经优于 persistence on 93% 像素，此项不激活 |
| **Pearson 相关** (已删除) | 替代 MSE 的趋势度量 | — | ❌ 无效 | 度量的是空间相关(0.98)而非时间相关(0.09) |

## 6. 下一步改进方向

当前模型已经逼近 **Earthformer 一次性 7 帧输出架构在 SST 预测上的性能上限**。进一步改善需要在架构层面引入时间递推机制。

### 方向 A：自回归训练（推荐优先尝试）

**改动方式**：修改 `training_step`，让模型只预测 1 天，然后将预测结果滚入输入窗口：

```python
# 伪代码
window = X[:, :14, ...]           # 初始 14 天输入
preds = []
for t in range(7):
    delta_1d = model(window)      # 只预测下一天的变化
    pred_t = window_last + delta_1d
    preds.append(pred_t)
    window = shift_and_update(window, pred_t)  # 滚动窗口
loss = total_loss(preds, Y)
```

**优势**：
- 不修改模型结构（CuboidTransformer 不变）
- `pred[t+1]` 的输入包含 `pred[t]`，天然有因果依赖
- 直接打破 ACF=0.985 的问题

**代价**：
- 训练速度约 7 倍慢（每样本要做 7 次前向）
- 需要处理误差累积（train with scheduled sampling）

### 方向 B：时间差分目标

**改动方式**：不改架构，改变预测目标为每日变化量而非累积变化量：

```
当前: delta[t] = SST[t] - SST[input_last]  (累积变化)
改为: delta[t] = SST[t] - SST[t-1]          (每日变化)
```

**优势**：改动极小（只改 `__getitem__` 的 Y 构造和 `training_step`）
**劣势**：预测时仍需逐日累加，累积误差可能更大

### 方向 C：Causal Decoder Self-Attention

**改动方式**：修改 `cuboid_transformer.py`，给 Decoder 的 self-attention 加上 causal mask，使 `output[t]` 的 self-attention 只能看到 `output[:t]`。

**优势**：保持 7 帧并行输出的计算效率
**劣势**：需要侵入式修改 `CuboidTransformerDecoder`，改动量大；且单向注意力仍不能保证学到递推动力学，只是给了一个必要但不充分的条件

### 优先级建议

```
1. 方向 A（自回归训练） — 改动量中等、效果最确定
2. 方向 B（时间差分目标）— 改动量小、可与 A 结合
3. 方向 C（Causal decoder）— 改动量大、效果不确定
```
